# PROJECT_CONTEXT

## Vision
Synapse AI ERP is a next-generation Enterprise Resource Planning system that transitions away from traditional CRUD-heavy interfaces toward intelligent, predictive, and deterministic supply chain management. It leverages deterministic mathematics, ML (XGBoost), and what-if simulation to provide actionable insights for inventory, supplier risk, and forecasting.

## Current State
- **Backend (Complete):** Fast API, SQLAlchemy, XGBoost integration. Includes Inventory Math, ABC Analysis, Stockout Risk, Dead Stock Detection, Supplier Intelligence, and a What-If Scenario Simulation engine.
- **Frontend (In Progress):** Phase 4 is beginning. We are transitioning to a modern Next.js 14 frontend using App Router, Tailwind CSS, and Framer Motion.
